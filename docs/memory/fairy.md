## Decisions / deviations (owner to confirm)

- Go-invented and kept: crit odds 5 / 50 per mille, the owner pace curve (2026-10-25), +100 doh per material, daily 20 grows / 10 feeds (the Flash
  default text says 5 feeds), new fairies start with full satiety.
- H5 hardening: raise accepts only types 601-605 (Go took any item); onSkill checks grow level >= book req_level and 20 slots (client-only in Flash);
  learn refusals answer `sindex` 1; adopt / shop menu picks need the NPC's map.
- Silver follows the selected money type (Go: unbound `money`); daily reset on the UTC+7 day (Go: UTC).
- Skins: owning a fairy of a template counts as owning its skin (Go refused it while the client lists it as owned); tids 15 / 16 refuse the gold
  unlock (client says "needs an item", no item exists); a skin change while guarding re-sends onFairyOn (H5: server-derived look).
- Releasing the guard sends onFairyOff + stat refresh (Go only onDelFairy). Satiety never decays (Go has no battle drain either; the guide text says it should).
