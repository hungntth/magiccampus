# Chân Hồn Thần Thú (PRS, M13 phase G 13.6c)

Built 2026-11-12. Research: `docs/research/2026-11-12_02_FAIRY_PRS_RESEARCH.md` § PRS. Plan: `docs/plans/2026-11-04_16_APPEARANCE_GEAR.md` § 2.6c / Phase G.

## What

Soul tree (50 nodes, Chân Hồn Thạch), Thần Dụ forms (10 goddess forms for 10 chips each, 12 time-limited special forms for event items), chip bag +
3 exchange slots (3 different chips -> 1 random), crystal exchange, collects (free with Lộ Thu Thập, 148 / 888 gold). Stats go to the **battle pet**.
Entry: activity strip icon 58 (seed row type 2 flag 50 = level 50).

## Contract (`packages/shared/src/prs.ts`, generated `prsData.ts`)

- RPCs (Flash names, first arg = cid, ignored): `initPRSPanel` -> `PrsPanel`; `addSoulTreeLvl`, `replacePRSShow(cid, showId)`, `cancelPRSShow`,
  `activePRSShow(cid, showId)`, `activePRSShowSpe(cid, showId)`, `movePRSChip(cid, from, to, direction 1|2)`, `exchangePRSChip(cid, chipId)`,
  `updateActivePRSShow({id: id})`, `freePRSCollect`, `goldPRSCollect`, `goldPRSCollectThree`, `swapPRSChip`, `swapPRSChipTimes` -> null.
- Pushes: `updatePRSPanel(PrsPanel)`, `updatePRSChipBag(bag)`, `updatePRSExcBag(bag)`, `onReplacePRSShow({cid, prsUseId})` (map broadcast),
  `onGetPRSChip({t:127, id, num})`, plus `onAddMoney(cid, key, delta, total)` + `onUPP` for realSoulStone / realSoulCrystal / realSoulWater / gold,
  `onRefreshPetProp` for the battle pet. Refusals: `RpcException.forbidden(PRS_TEXT.*)` + `onSystemMidMsgOrNote`.
- `PrsPanel` objects are never null, `tid` is a number. `PlayerData.prsUseId` (login) and `SceneCharacter.prsUseId` carry the equipped form.
- Pure helpers (tested): `prsTotals` / `prsRawSums` (tree rows with level <= level(tid) + actArr forms + unexpired timed forms), `prsPanelValue`
  (1/4/5/6/7/11 raw, rest / 100), `prsTreeView`, `prsFormState`, `prsExpiredForms`, `prsChipCount`, `prsTimeLeft`.
- `prsData.ts` is generated by `server/tools/gen-prs.ts` (tree / show / chip rows + tab-1 item names); re-run after a seed import.

## Server (`server/src/modules/prs/`)

- `prs-state.ts` (feature key `prs`, tolerant decode of the Go shape incl. string tid), `prs-rules.ts` (pure plans), `prs-collect.ts` (drop table
  parser + rolls), `prs.service.ts` (panel, tree, forms, move, exchange, expiry), `prs-collect.service.ts` (collects, swaps), `prs-pets.service.ts`
  (PetStatProvider `prs` + look hook + onRefreshPetProp), `prs.rpc.ts`, `prs.module.ts` (registered in `app.module.ts`).
- GameDataService: `prsTree/prsTrees/prsShow/prsChip/prsChips/prsCollectRaw` (`gamedata/prs-data.ts`); the drop table is read once at startup from
  `game_tuning_prs_collect` (restart to apply an edit; Go re-read it on every collect).
- Flow per call: `withCharLock` -> load + prune expired timed forms (write back, look re-broadcast when the equipped one expired) -> pure plan ->
  conditional spend (`CurrencyService.spend` / `CharacterService.spendMoney(gold)` / `InventoryService.removeByTemplate`) -> write (currency refunded on
  a failed write) -> credits -> pushes. Collect draws happen in memory and nothing is charged when the bag cannot hold them.
- Pet side: provider contexts panel / battle (battle pet only) / ppve (every line-up pet), like the handbook provider; dictionary `PRS_PET_PROPS`
  (`TALENT_PROPS` + 14 + 34). `PetFollowService.setLookHook` (registered by PrsModule) adds `prsUseId` to scene characters, swaps the following pet's
  `resCode` to the form art while it is the battle pet, and `PetBattleService.fighterOf` uses the same art for the pet fighter (Flash BattleCreatureView).
- `/grant prschip <id> <n>` (gmGrant kind `prschip`, `progression/grant-growth.ts`); currencies via `/grant currency realSoulStone|realSoulCrystal|realSoulWater <n>`.

## Client

- `game/PrsController.ts` (owned by `ActivityController`, strip id 58), window `ui/pet/prsPanel.ts` (FeatureWindow, tabs Thăng Cấp / Thần Hóa /
  Đổi Thần Dụ) drawn by `ui/pet/prs/{treeTab,formsTab,chipsTab,prsTypes}.ts` + `prs.css`.
- A click moves a whole chip stack bag -> first free exchange slot, or slot -> the bag end (the Flash used drag and drop). Gold collects confirm first.
  A 60 s timer sends `updateActivePRSShow` while the window is open and a timed form has expired.

## Decisions / deviations

- Swap follows the client text PRS_PANEL[15] (three different chips, one of each consumed per swap; Đổi Nhanh = as many swaps as the smallest stack);
  Go rerolled every staged chip 1:1. Owner to confirm.
- The chip bag is merged per chip id and compacted to 1..N; `activePRSShow` refuses tab-1 forms; timed forms always count minutes; the server clock
  decides expiry (Go trusted the client list); `onReplacePRSShow` is map-wide; `replacePRSShow` / `cancelPRSShow` also push `updatePRSPanel` to self.
- Go-invented and kept: stone / crystal amounts per collect, uniform chip weights, the six-collect guarantee default (matches PRS_PANEL[38]).
