- Some files are CRLF (e.g. `server/src/app.module.ts`, `modules/scene/scene.rpc.ts`); scripted find/replace must normalise line endings. `grep -c $'\r'` in the Bash tool is unreliable.
- Module cycles: `CharacterModule` cannot import modules that import it. Use `GameGateway` hooks (`onDisconnect`, `onCharacterLeave`) for cleanup, and let `SceneModule`/`ChatModule` import `PartyModule` (not the reverse).
- `nest start --watch` restarts on every server edit and drops all sockets and in-memory state (parties): re-login in the browser after each server edit.
- Browser testing: `javascript_tool` times out at 45 s; use DOM clicks for HUD/menus (`.team-tile`, `.player-menu-item`, `.confirm-dialog button`) and real pointer clicks for Pixi entities.
- Phase B party: Flash has no map-wide team-flag push (`onSetTeamLeague` is the league badge); H5 uses `onGroupFlag`.
- Browser tests: the pane is hidden, so Pixi walking/animation is throttled (clicks barely move the player); drive encounters with a scripted ws bot (login md5 from shared dist, `cbom` loop) instead. `gmGoMap` puts chars at spawn (100,100), a tiny walkable pocket: set `posX/posY` in Mongo (e.g. 1436,528) after disconnecting. Other sessions use accounts like `bt_ui_*` on the same map; clicking an unknown entity can invite their character.
- Scripted edits: bash `/tmp` is not visible to node on Windows; keep helper scripts in the scratchpad dir and normalise CRLF (`app.module.ts`, `use-item.*`, `bagActions.ts`, `hud/*.ts`, shared `inventory.ts` are CRLF). A heredoc holding many test files can fail to parse: use the Write tool for files.
- Pets (phase A): `PetModule` imports `InventoryModule`; the reverse call goes through `UseItemService.setPetHook` (cycle-free). Quest finish holds `withCharLock`, so `PetService.award` never locks (the lock is not reentrant). Server tests import `@mc/shared` dist: run `pnpm --filter @mc/shared build` first.
- Browser tests: drive DOM with `javascript_tool` (dispatch `KeyboardEvent` on window for HUD keys, `dblclick` MouseEvent on `.bag-panel [draggable]`); screenshots can lag a hidden pane, re-read the DOM. A CSS edit makes vite reload the page back to the login screen. `Bot` helper idea: global `WebSocket` in Node 24, no `ws` needed.

- Several combat/client files are CRLF (fighters.ts, BattleController.ts, battleMenu.ts): scripted replace must normalise CRLF; Edit with LF text fails on them.
- Big bash heredocs with backticks/apostrophes sometimes truncate or fail to parse in this harness: write long files/scripts with the Write tool.
- Phase C pets: pet fighter = `kind: 'pet'`, slot owner+5, `ownerCid`; `resolveRound` takes pet commands from the same slot-keyed Map, missing -> `petFallbackCommand`. Combat tests build Fighters inline, so widening `Fighter` fields must stay optional.

- Scripted edits via node -e inside bash double quotes: a backtick in the replacement text runs as a command and vanishes; write it with a Write-tool script file instead. browser_batch items need their own tabId (other sessions own the active tab).
- Hidden-pane battle trigger: patch WebSocket.prototype.send in the page, click the map once to capture window.__ws, then send {t:'call',id,m:'cbom',a:[x,y]} frames in a loop until .battle-menu appears; enemies are real-clicked at their screenshot coordinates.
- Phase D pets: caught creature = Fighter.caughtBy (catcher slot), pets created in BattleSettleService.contractCaught, onAddPet in MemberResult.catchPushes (sent last). Pet objectives (quest kind 3) are synced/consumed via PetObjectiveService; objective q = require row at the same index.
- Phase E pets: pet gear = character_items slotType 6, slotIndex petId*8+(pos-50) (shared petEquipSlotIndex); PetModule cannot import CharacterModule (cycle), so gold is charged through PetGoldService on the Character model. Stats go through `PetBonusService.extrasOf(cid,row)` -> `statsOfPet/propertyOfPet/petView(..., bonuses)`; pass it from every new view/battle caller. `rep.cjs` (scratchpad) = CRLF-safe exact replace driven by a JSON spec written with the Write tool; heredocs with apostrophes inside bash still fail to parse. Test pets/gear: set `pets.level` AND `exp` in Mongo (level is stored); login in the browser needs a click on `.char-list .char-card` before `.panel > button`.
- Economy phase A: `InventoryService.capacity(characterId)` is async (per-char opened pages); `bagSlotNum`/`bankSlotNum` defaults apply on read (`?? 1`, use `$max` to write). Repair lives in InventoryModule (Character model, no CharacterService: cycle). Move planners run over sid-keyed rows (slotIndex := sid). Page gate: `PageGate` + `session.bankOpen` (reset in `SceneManager.join/leave`).
- Browser tests: capture the game socket with `WebSocket.prototype.send` only when `this.url.endsWith('/ws')` (Vite HMR socket otherwise overwrites it); NPC dialogs/shops auto-close when the player is >300 px away, so set `posX/posY` near the NPC in Mongo and re-login. Hidden pane has 0x0 viewport: `resize_window` 1000x700 first. Fresh account: register via the login form; DragEvent dispatch (dragstart/dragover/drop/dragend) drives bag drag and drop; move RPC throttle is 1100 ms.
- Economy phase B: shop buy pipeline is `ShopService.settle` (shared by NPC and mall); `PlayerData` now carries selectedMoneyType/GoldType; bot tests must call `sceneLogin` after `chooseCharactor` or `session.mapId` is 0 (NPC-shop check fails). Mall shop NPC schedules (`at`) hide some NPCs: pick slots from shops 1-4 on map 1.
- Economy phase C (forge): `modules/forge/` (pure `craft-rules`/`quality-roll`/`mix-rules` with injectable Rng). Instance rolls live in `character_items.properties` (+`star`); stats read them via `equipBonusesOf`. Forge entry = HUD red column "Chế tạo" (`miniMap.ts` FUNCTIONS); tabs appended in `game/ForgeController.ts` FORGE_TABS. Test setup: mongosh script via `docker exec -i mcgame-mongo mongosh mcgame --quiet < file.js` (counters `_id:'items'`), account forgec01 char 25. Shell `node -e` with backticks/`${}` mangles code: write helper .cjs files (scratchpad) or use Edit (it handles CRLF files fine now). Recipes with `recipe_plan` rows are ids 1001+ (jewelry, req_level 66+); plain ColorCode path e.g. 646.
- Economy phase D (upgrades): `BagController.list()` is bag-only (comment lies); forge host items = `[...bag.list(), ...bag.equipped().values()]`. Refusals are `RpcException.forbidden(note)` caught by `forge/forge-guard.ts guarded()` (toast + legacy fail reply). Stat keys in `onUPP.property` are `finalMAttack`/`finalHp`/`finalDefence`. Fixture `d_items.js` (scratchpad) seeds forgec01: ring tpl 4 (next 117, materials 7/22/25 at colorCode 3), stones 5, diamonds 16, gems 11/65/47, soul 1659; equip a row by setting slotType 1 / slotIndex position-1 in Mongo then relogin. Pane tab cap is 8: reuse an idle `tab-N`; `getUpgradeInfo` right after a delete push races (errors are swallowed client-side).
- Economy phase E (transport/rename): `modules/transport/` (imports SceneModule+InventoryModule+PartyModule). Hidden pane: chat commands need a real click on the chat input + `key Return` (synthetic Enter is ignored); map 1 has safe_flag 1 (no encounters), use map 2 (1800,900) for bot battles. Bot e2e scripts live in the scratchpad (tp_e2e.mjs); browser test account via register form with random values generated in-page.
- Guild phase B: `grep -c ... && node - <<EOF` skips the node edit when grep finds 0 matches (exit 1); use `;`. Stats-side data comes through models (StatsModule imports guild schemas, not GuildModule). GameScene.ts is at its line cap: attach scene layers via `PortalLayer`'s `SceneCompanion` arg and pass deps through controller hosts. Bot e2e `b_e2e.mjs` (scratchpad) seeds bank/guild via `docker exec -i mongosh` stdin; strip the `mcgame> ` prompt from its output. Entity (kind npc) renders building art sheets (NPC_FUNC_000095..99 only; 100-108 are not in the cache).
- PvP (guild/PK phase C): PvP rides the PvE pipeline (`Battle.pvp`, target side `'enemy'` with `kind 'character'`); round/readiness/command-targeting are side-agnostic (`kind !== 'creature'` = command-driven), settle branches in `settlePvp`. Browser PvP check: one tab + `pk_bot.mjs` (scratchpad) auto-playing the other side; forced-PvP maps have `pk > 0` (map 5), `s_area` rectangles only on map 2000. A heredoc containing an apostrophe silently aborts the whole bash command: use the Write tool for scripts.
- Browser pane viewport emulation is cleared between turns AND sometimes mid-session: re-run `resize_window` 1100x720 before
  `find`/login when `find textbox` returns nothing. Batch clicks by coordinate need a screenshot earlier in the same batch.
- Re-login of the same account from a script kicks the old session; before 2026-11-05 the kicked close handler cancelled the new battle.
- preview_logs `search` is a plain substring (no `|` alternation).
